# B.3R physics and performance viability — failed correctness checkpoint

Decision: **the existing parallel solver has not earned further architectural confidence for packed cargo.** All three locked profiles rejected the canonical packed cases under the interim `.002` grain/solid limit and rejected the 8,192-grain combined workload before warmup. No profile supplied 600 accepted samples, so throughput is unproven. Both the [1.8 position over-relaxation prototype](#2026-09-24-convergence-prototype-and-decision) and [deeper full-graph relaxation](#2026-09-24-coupled-full-graph-relaxation-prototype-and-decision) failed and were rejected. Keep candidate damage/fuel paused and R1/B.GATE open. The subsequent [V2 design checkpoint](B3R-v2-design.md) selects a genuinely different coupled formulation and defines its staged validation. The next task is V2-0 independent reference and immutable replay; the solver is not yet implemented or adopted. Historical measurements below remain unchanged.
