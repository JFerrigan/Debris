# B.3R physics and performance viability — failed correctness checkpoint

Decision: **the existing parallel solver has not earned further architectural confidence for packed cargo.** All three locked profiles rejected the canonical packed cases under the interim `.002` grain/solid limit and rejected the 8,192-grain combined workload before warmup. No profile supplied 600 accepted samples, so throughput is unproven. Keep candidate damage/fuel paused and R1/B.GATE open. The next task is a reviewed packed-contact convergence change: quantify stronger position coupling or more sweeps from the saved failing state, including its GPU cost, then re-run this same fixture. That changes the locked numerical/iteration contract and needs its own decision before implementation.

That wall constraint has grain degree 6 and body degree 200; a roughly `.000327` wall correction produces only about `.000013` net grain movement because neighboring packed constraints oppose it. This supports insufficient coupled convergence as the concrete hypothesis; it does not justify an isolated arithmetic patch.
